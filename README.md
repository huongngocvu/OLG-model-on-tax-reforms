Codes to solve the model in "Macroeconomic effects of income and consumption tax reforms in New Zealand" by Robert Kirkby, Huong Ngoc Vu, and Yao Yao.

The article is available at https://www.sciencedirect.com/science/article/pii/S0164070426000200

The code requires the VFI Toolkit and GPU to run.

The VFI Toolkit is available at https://github.com/vfitoolkit.
